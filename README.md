# 归途 · LAST LIGHT

Windows 单人 3D 战争叙事游戏原型，源码版本 0.8.0。

本版重建城区边界、任务链、章内保存、车载机枪与连续切章。功能与验证范围见 `RELEASE-NOTES.md` 和 `VALIDATION.md`；最终Windows产物、启动验收和公开下载校验见[0.8版本发布记录](https://github.com/nnyy-yn/last-light/releases/tag/v0.8.0)。

根据讨论形成的16个剧情节点制作，包含192个主线现场行动、10个可选掩护任务、32次现场判断与16次章节选择、持续资源与关系状态，以及按玩家决定生成的尾声。城市以真实比例、表面扫描材质、昼夜光照和骨骼动画人物呈现。

这是可运行的独立游戏原型。损毁建筑与救援车辆采用程序化建模；新人物由 MakeHuman 官方基础资产重新生成，烧毁轿车、军装、六种枪械与UH-60使用公开授权模型。尚未达到商业3A作品的模型、动画、配音、AI和镜头演出规模。部分章节以地面互动和对白浓缩影片事件，没有完整的飞机驾驶或车辆驾驶系统。

## 0.8 城区、交火与连续演出

16章现在分别加载16个独立地图，切章会卸载上一场景的建筑、碰撞、火烟和人物。诊所、机场营房、简报机库、索降街道、抓捕庭院、第一坠机广场、市场巷道、车队S弯、第二坠机驾驶舱、防御圈、救治室、夜间院落、援军大道、转运废墟、黎明撤离路线和基地纪念区各有不同的布局与任务位置。

0.8 的15张场景外部边界为 240 × 240 米，第15章黎明撤离场景为 280 × 280 米；尺寸表示场景范围，不表示范围内每处都可步行到达。原剧情核心外增加相连支路、绕行环路、住宅院落、商铺和工棚；新增建筑有实体碰撞，院落入口和内部空地可走。第9章仍按剧情限制受伤机长在驾驶舱内行动，扩大的外部街区用于坠落与救援演出。

地图边缘已用连续实体建筑、封闭院墙和后排楼群围合，模型与碰撞一致。非任务支巷以可见院门收口，低矮商铺后补上有体积的楼群；可走的环路、院落及车队路线保持畅通。窗洞和破损商铺的内室有视觉深度，但非院落楼体仍使用整栋占地碰撞，并非每栋都可进入。

全部章节共用重建后的远景建筑系统：真实窗洞和内室深度、楼板、阳台、错层屋顶、储水设施与断墙；可玩外围使用同一模型并配置相符的碰撞。机场与城区使用不同的建筑/道路布置，保留相应的历史地点与气候设定。

地面重建使用连续三角网格，城市道路包含缓坡、车辙、凹坑、破碎边缘、沙肩与下沉排水沟；人物、弹着点、弹壳和剧情演出的地面动作读取同一高度。营地、机库和室内保留相应平整作业面。城市路边按市场、维修院、货仓、坠机废墟分别布置，远景以有限支路、院墙和街坊收口；五处室内与基地新增医疗、生活、维护和纪念设施。

白天光照重新平衡日照与背阴区，高画质增加半分辨率的小范围接触阴影，辅助表现墙根、路沿和物件接地；中、流畅画质关闭这项额外效果。低位风尘和纸屑沿当前章节真实道路分布，室内不生成户外风源。场景仍为手工编排与程序化几何的组合，不是照片扫描整城或可实时坍塌建筑。

每章按四段任务链组织，共192个必做行动与10个可选掩护任务；任务对白表共607句，包含可选任务，不含开场广播、选择回应和尾声文本。32次现场判断会实际改变救护物资、信任、凝聚力或居民获助状态；物资不足时提供其他可选安排。相同剧情人物共用同一个场景角色，新增交互复用既有伤员，护送阶段按原流程切换移动姿态。任务使用有姓名的现场人物和随身无线电进行双向交谈。按一次E推进一句，读完后执行救治、补给交接、抵达、护送或防守行动；随身无线电不生成桌面收音机。三项护送检查真实同行人物是否到达，三项防守需要在指定位置坚守并击退敌人。战斗地图保留既定敌军，增加外围守备与从已有街巷接近的增援。初始接敌点必须有实体掩体，不再把两名敌人直接放在出生视野正前方的马路中央。敌人按掩护、左翼、右翼分工移动，受压制后收回掩体；视线、枪声、烟幕、有限弹匣与换弹共同限制开火。非战斗角色的地图没有敌人。第9章机长留在受伤驾驶舱，不能步行穿越城区。

城区增加独立街区居民，交战时从暴露路边跑向掩蔽位置并蹲伏；居民不持枪，不承担敌人AI。位置和撤离通道需通过街道宽度、碰撞和任务区域检查；他们与剧情护送人物分别管理。

车队采用重新制作的低矮宽体HMMWV和独立六轮运兵卡车。第5章主队为9辆悍马、3辆卡车，伤员送返演出抽出3辆悍马；第8章保留余下9辆。第13、15章展示12辆援军车列，属于更大救援队的可见部分，尚未复原历史夜间救援中的全部装甲车与坦克。正常地图也保留对应车列；演出使用按车辆长度保持间距的连续路线、减速转弯、停车与重新起步，并带驾驶员、枪手、车轮转向、发动机距离声和近地扬尘。这些是参考电影与资料重新建造的原创模型，不是电影资产或完整历史复刻。

保留16段开场、16段结尾与48段关键剧情演出，并为新增现场行动提供局部实时演出，均为游戏内实时3D脚本动画：包括索降失足、直升机尾部中弹与旋转下降、撞地扬尘与火烟、车队转弯和驶入、担架转运、室内救治及跑步撤离。可以暂停或明确点击跳过；不使用电影视频或原片对白录音。对话当前为字幕与人物骨骼动作，没有真人配音或口型捕捉。

完整战役在选择后播放本章结尾，经过与离场/抵达演出衔接的遮挡转场，自动开始下一章。15次交接注明下一地点、时间与角色；并行发生的事件不会被描述成同一人走到另一处。交换场景时遮罩保持完整覆盖，暂停冻结转场；取消或退出不会执行迟到的场景交换。章节仍独立构建和卸载，并非整城无加载流送。

战斗中的悍马 M2 会转向有真实视线的目标，有限弹链、过热和换弹规则同时约束 AI 与玩家。V 接管后使用实际枪塔射线、双手握把、100发弹链与独立储备，R 更换弹链；步兵枪械弹药不会被挪用。下车必须有可站立净空。G 指定小队压制方向，Q 烟幕遮挡双方视线，F 仍用于跟随/坚守。普通步枪不再每一发都画慢速长曳光，弹着按砂土、墙面和金属给出不同的碎屑、火花与声音。

主菜单“亲自索降”可直接体验第4章，并保留原战役存档；“坠机救援”进入第6章战斗演示。

关键演出由玩家参与：E控制索降（松开抱绳）、持续救护与协同抬运，A/D在受损驾驶舱里尝试压住机身倾斜，W/S控制撤离人物前进或后退。右键拖动可限幅观察。未输入时操作不会自动完成，周围旋翼、烟尘与车队仍继续活动；Esc暂停会冻结整个演出。这些是有边界的剧情操作，不是完整飞行模拟。

[在线试玩](https://nnyy-yn.github.io/last-light/) · [Windows下载与版本记录](https://github.com/nnyy-yn/last-light/releases)。

章节以首玩20–25分钟为内容设计目标，现有分钟预算尚未经完整正常游玩测定，不能作为已达标的时长承诺。运行时记录截至章末选择的活动时长（含开场及任务演出），排除暂停与菜单；没有强制等待、减慢移动或重复刷取的最低时长门槛。自动化测试使用明确披露的路线定位和跳过演出，只验证流程、碰撞、保存和衔接，不验证首玩时长。

## Windows启动

可使用单文件便携版，或保留完整运行库的目录版。

- 单文件便携版为 `release/归途-LastLight-v0.8.0.exe`。所有游戏资源随包提供，首次解压需要等待片刻，无需联网、Node.js或开发环境。
- 也可以打开 `release/归途-LastLight/归途.exe`。目录版需要保留旁边的资源和运行库，不能只移动这一份exe。
- Windows x64；建议使用支持WebGL 2的独立显卡或较新的集成显卡。画面设置提供流畅、均衡、高三个档位。
- 游戏进度保存在本机用户数据目录的 `LastLight` 应用数据中。每次完成现场行动后保存章内检查点，包括已完成任务、现场决定、物资、六把武器的弹匣、已击倒敌人、烟幕数量和M2剩余弹链。继续归途恢复最近行动；暂停菜单另提供整章重来。未完成的行动从上一检查点重试，不重复领取补给。任务数据更新导致签名不匹配时，会提示并回到本章起点；不保证跨内容版本精确恢复章内位置。
- 本地自制程序未附带商业代码签名。

所有重要选择都会暂停场景，允许从容阅读。舒缓模式降低伤害和奔跑消耗。非战斗角色不能开枪。战斗章节可以利用建筑避开交火，完成救援目标，无需消灭全部敌人。

主菜单“进入坠机救援”直接进入第六章战斗演示，保留原有完整战役存档；“开始完整剧情”从居民视角开始。战斗章节的敌人从掩体和侧巷接敌，探身点射后可回撤、换弹或绕行。武装人员使用AKM，掩护队员携带M249，普通队员使用M16A2。

0.6重做交火、场景互动和夜间照明。枪口使用短促分层闪光，曳光是移动短段；弹着按沙土、墙体和金属区分尘屑/火星，有有界弹孔、弹壳反弹和受击方向提示。旋翼加入已获公开领域许可的实地录音，并与低频拍击、涡轮及风压分层混合；声音随飞机距离、方向和接近/远离变化。枪声和爆炸采用原创合成的瞬态、低频主体、衰减和反射，换弹声跟随实际动作阶段。可分别调节总音量、直升机音量、交火与爆炸音量。采样机型未确认，来源见 AUDIO-SOURCES.md。

战斗章节路边有两个可搜索的实体箱：弹药箱 +24 共用备用弹药，医疗箱 +1。瞄向并靠近箱子按住 E，松开或暂停会取消；每箱每章仅可取一次，打开盖子后保留实体碰撞。F 让队员就地掩护或继续跟随。Q 每战斗章有两枚地面发烟罐，约3秒展开、18秒消散；烟幕遮挡双方 AI 视线但不挡子弹。没有完整的烟雾投掷手部动画。

第11—13章采用真正低照度夜景：天空、环境反射和天光均显著降低，大多数街灯熄灭，火点和少量灯具形成局部亮区。T 开关局部手电，默认关闭；高/中/流畅画质分别使用1024/512/256像素手电阴影；流畅档关闭大范围天光阴影并保留手电的遮挡。夜间敌人远处发现能力降低，打开手电会增加被远处发现的可能。夜景是关卡照明设计，不声称重现战斗当晚月相或逐盏真实供电状况。

模型改造包括六处带厚墙、破口、楼板和室内隔间的近景废墟；新PASGT风格头盔、扁织带、扣件和士兵局部领口/胸前装备；AKM木质枪托/护木、M249枪托及布质弹袋。其余四枪保持既有模型。原16章、48个核心任务及章末选择路线继续保留，并被编入当前192个必做行动。本版仍是独立原型，不能作为“全内容已达到3A”交付。

0.5继续细化模型与手部：第一人称恢复完整68骨手臂蒙皮，五指、手腕、肘部和枪械分件分别运动，换弹时支撑手离开护木、抓取弹匣、移向携行位置、回插再回握。不同枪使用各自源模型的弹匣，M249使用新增布质弹袋与短弹链；这仍是游戏化动作，M249没有完整可开合机匣盖及内部供弹机构。第三人称同步加入转腕、收放手指和真实弹匣移出。换弹时间与原有弹药预算不变，动画结束后才完成装填。

模型局部改造包括M249弹袋、缝线和枪口内壁，M16A2/AKM保留原UV的弹匣分件，以及六枪分材质粗糙度；人物增加局部皮肤法线和粗糙度、修正眼睛与领口；街边柜体、轮胎、手推车轮组、墙体断面重新建模。新增几何集中在近景物件，没有把整体细分或贴图放大当作质量提升。角色与武器仍沿用已有授权资产，其原始细节精度构成当前上限。
0.4用有明确授权的PBR网格替换此前简陋的M249和AK模型，增加M16A2、MP5与M1911，保留M4A1，共六把可用枪械。数键顺序为 **1 M16A2、2 M249、3 AKM、4 MP5、5 M1911、6 M4A1**。各枪拥有独立弹匣、容量、后坐和开火间隔；M16A2为三发点射，M1911每次扣动一次，其余为自动射击。空枪切入后有剩余补给则自动装填，装填期间不能切换。弹药仍是叙事游戏共用的抽象补给预算，没有模拟现实中不同口径的供应体系；切枪不会凭空增加弹药。

剧情默认用M16A2。M4A1保留为扩展装备，没有把它改名冒充1993年的CAR-15。枪械来源、厂商/博物馆外观与年代参考见 `WEAPON-REFERENCE.md`，作者许可及实际修改见 `ASSET-SOURCES.md`。

地点为1993年10月3日至4日的索马里摩加迪沙，章节标明机场基地、Bakara 市场/Olympic Hotel 附近及救援撤离路线。建筑、道路和照明按暖湿沿海城市资料调整，地面包含不规则沙土、车辙、生活残留与战损路障。关卡压缩了现实空间，气候均值也不是战斗当天实况；史料、地图与气候数据见 `WORLD-REFERENCE.md`。

主菜单的“人物与装备”提供游骑兵、城市居民、武装人员三类人物，以及全部六种枪械的旋转预览，可切换全貌与细节近景；相机按照各枪尺寸调整距离。

人物使用 MakeHuman Community 的 MPFB2 2.0.18，在 Blender 4.5.9 后台实际重建体型、面部和 Mixamo 骨架，提供三套新 GLB。居民穿无品牌衬衫，武装人员穿灰褐夹克并持 AK、无美军头盔；士兵以新人体比例重新适配军装和头盔。皮肤与衣物使用最高 2K 贴图，运行时有脚底与握枪手掌的 IK。可编辑 `.blend`、参数 JSON、官方资源校验、重建脚本与导出哈希保留在 `character-sources/makehuman/` 和 `scripts/makehuman/`。这是 MakeHuman/MPFB 资产管线，未使用 MakeHuman 独立桌面程序；面部没有表情捕捉或完整口型演出。

0.3重做小队行动与交火反馈：前方队员和后方警戒采用不同队形点，利用道路和掩体绕障、交替掩护；敌人观察、寻找掩体、探出射击，丢失目标后搜索最后位置。近失弹和爆炸触发屈膝避弹与转移，剧情人物在互动时停步，救护队员到伤者身边半跪施救。角色采用分方向步态、转身踏步和真实骨骼蹲跪；短点射、有限弹匣与换弹动作连接成完整循环。子弹在掩体处终止，留下短促的弹着尘屑、火星和空间音效，近弹声随实际弹道位置变化。

街角加入废弃摊车、塌篷、散落货物与破损设施，灰土和瓦砾沿损坏位置延伸；远景楼体也有缺层、破窗与坍塌屋顶。横街与主街都有低位阵风尘土和少量卷动纸屑。倒地采用连续骨骼姿态与按实际人体网格修正的侧卧接地，目前仍是预设动作，没有完整布娃娃物理。

第一人称武器与人物携带武器共用对应枪体网格，并分别适配持握和瞄准位置。UH-60 按约15米机身、16米主旋翼呈现，加入双机低空飞行、随距离变化的旋翼音与下洗尘土。坠机处使用连续上升、随风扩散的浓烟柱和地面浮尘，建筑已改为墙段与楼板构成的壳体，近景包含大面积坍塌、露出的内室与断钢筋；碎墙堆集中在毁坏处，道路有坑洼、排水沟与破裂路缘。烧毁轿车使用实物扫描模型，燃烧由黄芯、橙色火舌、火星、闪烁光源与浓烟组成。高画质启用接触阴影、FXAA边缘抗锯齿与克制的火光泛光，中画质使用2倍几何多重采样。默认按显示器原生分辨率渲染，分辨率独立于阴影档位，可选择75%、100%、125%、150%，设置页显示实际渲染像素；桌面默认最大化。

## 选择如何影响游戏

- 弹药用于实际装填和射击，分享弹药会减少后续储备。
- 救护物资用于 H 治疗和部分剧情分支；物资不足时相关选项不可选，每章仍保留不消耗物资的推进方式。
- 疲劳降低移动和体力恢复；协助搬运时移动速度下降。
- 凝聚力达到一定程度后，同伴可在玩家重伤时提供一次支援。
- 信任、居民获助、特殊选择标记共同改变尾声文字。
- 重玩已到达章节会恢复该章资源与选择快照，并重写之后的路线，不能反复累计收益。

## 内容说明

主要事件沿用电影《黑鹰坠落》的叙事骨架；阿米娜、里德、米勒及互动对白、局部救援、心理表达与选择后果为原创改编。主要现实人物的影片结局固定。第九章以杜兰特的意识片段表达受困体验，地图移动不表示重伤者实际步行。

本作未使用影片画面、电影配乐、演员肖像或原片台词录音。声音采用原创运行时合成，并加入公开领域的直升机实地录音采样，来源见 `AUDIO-SOURCES.md`。模型与贴图来源见 `ASSET-SOURCES.md`，发行包保留对应许可证和署名。

浏览器版使用 Node.js 24 和 pnpm 11.25.0（与 GitHub Pages 构建一致）。在项目根目录执行：

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm test
pnpm dev
```

生产构建执行 `pnpm build`，产物为 `dist/`；可用 `pnpm exec vite preview --host 127.0.0.1` 本地预览。GitHub Pages 工作流仅从 `main` 的推送或手动触发部署；仓库的 Settings → Pages → Source 需设置为 GitHub Actions。浏览器版需要支持 WebGL 2 的桌面浏览器，当前静态运行资源目录约 116 MB（未压缩文件体积，不等同于实际首屏下载量）。Windows 打包需要对应版本的 Electron runtime 与 NSIS；配置方式见 `scripts/PACKAGING.md`。当前工作区也可直接运行 `scripts/build.ps1`。

公开 Git 仓库保留游戏源码、运行资源、生成脚本、参数和许可记录；大型 `.blend` 工程、重复的中间模型、工具下载及测试录像不入 Git。完整可编辑工程保留在 Windows 发行包的 `source/` 中。公开源码不代表第三方素材改为统一许可证，许可范围见 `NOTICE.md`。

浏览器验证脚本使用当前Codex运行时的Playwright路径；在其他电脑运行时需调整为本机Playwright安装路径。所有QA入口仅在开发URL明确带 `?qa=1` 时启用，正常桌面入口不启用。
