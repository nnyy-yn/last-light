# 近景环境模型源文件

本目录保留 v0.4 环境生成器基准，供模型对比和后续修改。`v0.4-baseline/` 是只读参考快照，原有相对导入路径没有改写，不能直接作为入口运行。

v0.5 的可编辑建模源为 `src/environment-detail.js`：全部新增柜体、轮胎、手推车机械结构和断墙断面均为本工程原创程序化网格，不依赖外部网络或新模型下载。使用米制坐标；子部件经调用方的矩阵烘焙后，合并到城市已有材质批次。四张局部材质图在运行时以固定种子绘制，共享作基色及细微凹凸使用。

固定构图预览与几何/通行验证脚本位于 `scripts/environment-detail/`。先运行本地 Vite（端口 5177），再运行 `node scripts/environment-detail/capture.mjs after`；该脚本仅启动 headless Chromium，通过页面函数设置静态相机，不移动系统鼠标、不显示窗口、不请求 pointer lock。

基准和改后截图、SHA、三角面/绘制调用数据位于开发验证目录 `artifacts/model-upgrade-v0.5/`。街道位置及碰撞盒未变；柜体、轮胎和手推车的主体体积保留在原有占地范围内。
